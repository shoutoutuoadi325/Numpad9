# Numpad9 商店介绍

产品名称：Numpad9 九键输入法。类别：Utilities & tools。价格：免费。

## 简体中文

简短描述：把电脑小键盘当作手机九键使用，离线输入中文拼音与英文。

Numpad9 把电脑小键盘转换为熟悉的手机九键位置。电脑顶排 7、8、9 对应手机 1、2、3；电脑底排 1、2、3 对应手机 7、8、9。按电脑实体键 6、4、4、8、6，再按空格，即可选择输入“你好”。

打开 Numpad9，启用九键输入，再将焦点放到普通文本框。空格或 Enter 确认候选，Escape 取消，Backspace 删除一个按键。/ 切换中文与英文，* 移动候选，+ 和 - 翻页。Num Lock 开启或关闭均按物理位置识别小键盘。停用九键输入后恢复普通小键盘操作；托盘菜单可退出应用。

应用提供双语键位指南和练习文本框，中文采用逐词拼音候选。词典和输入处理均在本机完成，没有广告、云端转换或个人输入历史。应用退出时丢弃练习文本。

需要 Windows 11 24H2 或更高版本、x64 电脑和实体数字小键盘。商店版使用当前 Windows 键盘配置。密码、PIN、受保护的私密字段和只读字段不参与转换；部分应用或提升权限的窗口可能限制输入访问。

功能：手机九键位置映射；离线中文拼音与英文；Num Lock 两种状态；双语指南与练习框；应用和托盘中的启用、停用及退出操作。

## English

Short description: Use your PC numeric keypad like a phone keyboard for offline Chinese Pinyin and English input.

Numpad9 turns your PC numeric keypad into a phone-style nine-key keyboard. Physical top-row keys 7, 8, and 9 act as phone keys 1, 2, and 3; bottom-row keys 1, 2, and 3 act as phone keys 7, 8, and 9. Press physical keys 6–4–4–8–6 and Space to enter 你好.

Open Numpad9, enable nine-key input, and focus an ordinary text field. Space or Enter commits the selected candidate; Escape cancels; Backspace removes a key. Use / to switch Chinese and English, * to move through candidates, and + or - to change pages. Physical keypad positions work with Num Lock on or off. Stop input to restore normal keypad behavior, or exit from the tray menu.

The window includes a bilingual key guide and a practice field. Chinese input uses word-by-word Pinyin candidates. Dictionaries and conversion stay on your computer. There are no ads, cloud conversion, accounts, or saved typing history. Practice text is discarded when the app exits.

Requires Windows 11 24H2 or later, an x64 PC, and a physical numeric keypad. The app uses the current Windows keyboard profile. Password, PIN, protected private fields, and read-only fields are excluded. Some applications or elevated windows may restrict input access.

## 使用说明与能力用途

Open Numpad9 from Start and select Enable nine-key input. Focus an ordinary editable text field and use the physical keypad positions shown in the app. Space or Enter commits the chosen candidate; Escape cancels. Stop nine-key input or exit from the tray menu to return to normal keyboard behavior. No account or network connection is required. Uninstall through Windows Settings.

The TextInputMethod capability supplies focus notifications, keyboard events, and edit sessions for the current input operation. The app reads only the insertion/selection range and its own composition, uses an offline dictionary, excludes protected fields, and clears pending composition when focus changes or input stops. It does not log or transmit keystrokes or typed text.
