## 中文

Numpad9 是离线九键拼音和英文输入法。用户启用并选中 Numpad9 时，Windows 输入服务提供当前输入交互的相关按键、焦点、输入范围和编辑会话。Numpad9 在本机内存中处理按键编码、当前组合文字及候选词，并把用户确认的文字交给当前文本应用。这些文字可能包含个人信息。

输入法只处理本次输入需要的插入点、选中范围和自己的组合输入；不扫描文档，不读取无关文档内容，不建立个人输入历史。Windows 标记的密码、PIN、私密、受保护字段，以及禁用文本读取或写入的控件不提供转换。未确认的输入在取消、焦点改变或服务停用时清除；这不是安全擦除进程内存的承诺。

按键、输入文字、候选词和输入历史不发送给发行人或第三方服务器。此版本没有账号、广告、统计分析、遥测、云词库或后台更新服务。内置词库只读，转换不需要网络。练习文本框只在窗口内存中保存文字，应用退出后丢弃。

MSIX 包由 Microsoft Store 和 Windows 安装、更新和卸载。应用不会自动修改默认输入法，也不自动在用户登录时启动。用户可随时停用输入服务或退出应用，并可在 Windows 应用设置中卸载。文字确认后，目标应用如何保存或传输该文字由目标应用决定；Windows 与 Microsoft Store 的下载、安装和诊断信息适用其各自政策。

应用中的源码链接在用户主动选择打开时使用系统浏览器。浏览器和 GitHub 按其自身政策处理访问及用户自愿提供的信息。隐私和支持联系为上述 GitHub 议题页面；议题是公开的，提交前应移除私人输入文字、账号信息或其他无关个人信息。若用户主动提供截图、日志或支持报告，项目会收到这些内容。Numpad9 不在后台收集支持资料。

## English

Numpad9 is an offline nine-key Chinese Pinyin and English input method. While you enable and select Numpad9, Windows text-input services supply relevant keys, focus information, input ranges and edit sessions for the current interaction. Numpad9 processes key sequences, active composition and candidates in local process memory, then delivers the text you confirm to the focused application. Typed text may contain personal information.

Access is limited to the insertion/selection range needed for the current input and Numpad9's own composition. The app does not scan documents, read unrelated content, or maintain personal typing history. Conversion is excluded from Windows-marked password, PIN, private and protected contexts and controls disabling text reading or writing. Pending input is cleared on cancellation, focus changes or deactivation; this does not promise secure memory erasure.

Keystrokes, typed text, candidates and typing history are not transmitted to the publisher or third-party servers. This version has no accounts, advertisements, analytics, telemetry, cloud dictionary or background updater. Conversion uses a bundled read-only dictionary without a network connection. The practice field retains text only in window memory and discards it when the app exits.

Microsoft Store and Windows handle MSIX installation, updates and removal. Numpad9 does not automatically change the default input method or start at login. You can stop the input service, exit the app, or uninstall through Windows application settings. Receiving applications control subsequent storage or transmission of committed text. Windows and Microsoft Store handle downloads, installation and diagnostics under their own privacy policies.

Source links open the system browser only when you choose them. Your browser and GitHub handle visits and voluntarily supplied information under their own policies. Privacy and support inquiries use the GitHub issues page above. Issues are public: remove private typed text, account information and unnecessary personal details before posting. If you voluntarily send a screenshot, log or support report, the project receives what you provide. Numpad9 does not collect support materials in the background.
