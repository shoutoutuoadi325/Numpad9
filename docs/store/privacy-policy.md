## 中文

Numpad9 是在 Windows 中运行的九键输入法。当你选中 Numpad9 并在文本输入区域输入时，Windows Text Services Framework 会将相关按键与输入上下文交给输入法。Numpad9 在本机内存中处理输入序列、当前组词和候选词，用于显示候选并将你确认的文本提交给正在使用的应用。输入的文本可能包含个人信息，因此本政策说明其处理方式。

Numpad9 不将按键、输入文本、候选词或输入历史发送给发行人或第三方服务器。该版本没有账号系统、广告、统计分析、遥测、云词库、联网预测或后台更新。词典包含在安装包内，读取不需要网络。该版本不建立持久化个人词库或保存用户输入历史。当前组合内容在结束、取消或输入上下文释放时从活动输入状态中清除；这不是对进程内存进行安全擦除的承诺。

Windows 在当前文本应用的进程中加载输入法组件。Numpad9 遵守 Windows 输入服务和应用容器权限；针对 Windows 标记的密码输入上下文不提供九键转换。用户输入最终交给目标应用，其后如何保存或传输由该应用决定。Microsoft Store 和 Windows 自身可能按各自政策处理下载、安装、错误报告或诊断数据，Numpad9 不控制这些服务。

安装会在 Program Files 中写入应用、词典和许可文件，并登记 Windows 输入法和卸载项。安装器可生成本地安装日志，包含安装路径、版本、操作结果及错误信息，不记录输入法的打字内容。卸载撤销注册并删除所安装文件；被占用文件可能在重启后清除。应用不会自动修改默认输入法或设置开机启动。

你可以在 Windows 语言设置中启用、切换或移除 Numpad9，也可以在 Windows 应用设置中卸载。若你主动向发行人发送支持邮件、截图或日志，发行人会收到你所提供的信息；提交前请删除不必要的个人内容。具体支持联系方式和处理责任方由下方真实发行人信息确定。

## English

Numpad9 is a local Windows nine-key input method. While you select Numpad9 in a text field, Windows Text Services Framework supplies relevant key events and text context to the input method. Numpad9 processes the input sequence, active composition, and candidates in local process memory to present choices and commit the text you confirm to your current application. Your typed text can contain personal information.

Numpad9 does not transmit keystrokes, text, candidates, or input history to the publisher or third-party servers. This version has no accounts, advertisements, analytics, telemetry, cloud dictionary, online predictions, or background updater. Its dictionary ships with the installer and works offline. It does not maintain a persistent personal dictionary or save your typing history. Active composition state is cleared when composition ends, is cancelled, or its context is released; this is not a promise of secure memory erasure.

Windows loads the input method component into the current text application's process. Numpad9 follows Windows text-service and app-container restrictions and does not offer nine-key conversion in contexts Windows marks as passwords. The receiving application controls how committed text is subsequently stored or transmitted. Microsoft Store and Windows may process download, installation, diagnostic, or error-reporting information under their own policies.

Setup writes application, dictionary, and license files under Program Files and registers the input method and uninstall entry. Local installation logs can include paths, versions, operation results, and errors; they do not log text typed through the input method. Uninstall removes registration and installed files. Locked files may be removed after restarting Windows. The application does not automatically change your default input method or run at startup.

You control activation and removal through Windows language and application settings. If you voluntarily send a support email, screenshot, or log to the publisher, the publisher receives the information you provide. Remove unnecessary personal information before sending it.
