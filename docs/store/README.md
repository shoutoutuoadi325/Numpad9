# Microsoft Store 发布信息

Numpad9 九键输入法在 Microsoft Store 使用 MSIX 分发，面向 Windows 11 24H2 或更新版本的 x64 电脑。GitHub 同时提供适用于 Windows 10/11 x64 的传统 EXE 安装包。

- 产品介绍与审核使用说明：[listing.md](listing.md)
- MSIX 身份、授权与打包：[msix.md](msix.md)
- 商店版隐私政策：[privacy-policy-msix.md](privacy-policy-msix.md)
- 输入服务能力申请说明：[laf-request.md](laf-request.md)

产品标识为 `9N82M2S3QS4C`，包标识为 `14E33A41.Numpad9`，发行人为 Zhiqi Zhang。Microsoft Store 为分发的 MSIX 签名并管理更新。应用采用 GNU GPL v3，完整对应源码、词典署名和第三方许可随版本提供。

商店页面使用中英文产品说明、实际界面截图、免费价格和 Utilities & tools 分类。隐私政策说明输入在本地处理，以及用户主动打开源码或支持链接时的行为。TextInputMethod 自定义能力的批准和最终认证由 Microsoft Store 处理。
