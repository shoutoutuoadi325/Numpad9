# Windows release QA

本清单是可选的内部验证参考，不作为本次发布的强制人工实机门槛。若执行条目，保留系统版本/build、候选版本、安装器 SHA256、截图/日志、预期与实际结果；不把未执行的条目填成通过，也不把核心单元测试写成 Windows UI 测试。

| JSON test ID | Steps and passing evidence |
| --- | --- |
| `win10-x64` | Fresh x64 Windows 10 1809/build17763 VM: install, select, Chinese+English composition, uninstall; record exact build. Also test a currently supported Windows 10 deployment if you claim it. |
| `win11-x64` | Fresh current Windows 11 x64 VM: same lifecycle; record version/build. |
| `standard-user-uac` | Start setup from standard user account, provide administrative UAC credentials; return to original standard-user session, discover and select input method. Standard user can type without elevation. Test another user to confirm machine registration and per-user selection behave correctly. |
| `silent-offline-install` | Disconnect network and use documented silent parameters on a fresh VM without separately installed VC++ runtime. Only UAC may appear, no wizard/finish/error boxes, no forced restart/app launch; exit0 or documented restart code. Confirm actual installed product/publisher/version and exactly one program entry. Verify no service/driver/task/startup/bundleware. On ARM64 and x86 OS, installer rejects cleanly. |
| `x64-tsf` | In real x64 Notepad/editor and browser text fields, select Numpad9 using Win+Space. Enter Chinese, confirm candidate, English candidates and punctuation. No duplicate keyboard; raw QWERTY keys and shortcuts stay usable. Save bitness and app versions. |
| `x86-tsf` | Repeat in known x86 editor/browser. Confirm HKLM32 COM path points to x86 DLL and HKLM64 path to x64 DLL; both use the same CLSID/profile. A 64-bit test app does not prove x86 compatibility. |
| `appcontainer` | Real Windows app-container editable text control: dictionary loads, candidate UI appears in correct position, committed text arrives. Exercise app-requested UI-less TSF candidates if available. No permission workaround. Capture package/app identity and output. |
| `password-scope` | Password field (e.g. a controlled test app with explicit password input scope) and other supported sensitive scopes: no conversion/candidate window; verify typed keys aren't logged or uploaded. Test secure desktop restriction and switching away. Never use a real password in evidence. |
| `numlock-layout` | Both Num Lock on AND off: PC physical rows 7/8/9→phone1/2/3, 4/5/6→4/5/6, 1/2/3→7/8/9. Enter samples that exercise every key, candidate previous/next, commit, erase/cancel, logical1 comma and decimal fullstop. With Numpad9 inactive, Num Lock off restores normal navigation. Ctrl/Alt/Win modified numpad keys don't trigger composition. Dedicated vs laptop Fn keypad hardware behavior recorded. |
| `composition-lifecycle` | Compose, cancel, Backspace to empty, Enter/Space confirm; change field/app/input method mid-composition; close app; trigger failed edit session/read-only/no-context; candidate window follows cursor/DPI and hides on focus loss; no crashes, stale candidate capture or swallowed ordinary keys. Long sequences/large vocabulary remain responsive. |
| `upgrade-loaded-ime` | Install a genuinely earlier version, activate x86 and x64 applications and keep DLLs loaded; install a newer version. New COM paths point to new folders; old processes remain stable and update after restart; no forced process termination. Same-version install and downgrade rejected with non-success exit rather than overwriting loaded binaries. |
| `registration-rollback` | On disposable snapshot VM, force second-architecture registration failure (e.g. deny narrowly scoped x64 CLSID write permission), install update, verify non-success result and restored prior x86/x64 COM/profile/categories. Clean the artificial denial. Also test initial install failure. Save setup log. Do not change production registry permissions for this test. |
| `uninstall-loaded-ime` | With both bitness apps holding DLLs, uninstall silently. Registration removed without crashing apps or switching system defaults forcibly. Close apps/reboot if needed, verify removal of both Program Files trees, Start entries, uninstall entry, CLSID/profile/categories and dictionary files; no unowned data deletion. Repeat standard-user initiates UAC uninstall and after an upgrade. |
| `defender-scan` | Update Defender definitions, scan exact signed installer and installed PE files on clean Windows; record engine/signature versions, timestamp and result. Check signatures of installed `unins000.exe` and any temporary setup copy where observable. |
| `accessibility-dpi` | Keyboard-only help window, Tab order, accessible names/Narrator, high contrast, 100/150/200% DPI, multi-monitor candidate placement and touch keyboard overlap. Record actual results; fix defects before passing. |
| `store-assets` | Real screenshots from tested Windows UI, correct app logo exports/current Partner Center sizes, bilingual descriptions matched to actual features, real privacy/contact/source pages reachable, installed privacy file contains no unresolved placeholders. Hosted EXE SHA256 equals tested artifact. Review age, market, permissions, architecture, license terms. |

Registration identity: CLSID `{E03FE2C4-24B9-4C4E-B605-88717E6A4D49}`; language profile `{859113AF-D94C-4FD7-8870-9B1F607E6896}`; language ID `0x0804`. Registry evidence should cover both views of `HKLM\Software\Classes\CLSID` and the TSF API-managed TIP/category/profile registrations. Read registry evidence without deleting broad Microsoft CTF keys.

Release structural checking is automated by `scripts/Validate-Release.ps1`. A copy of the JSON template may be supplied through optional `-QaReport`. Record only checks actually performed. Manual physical QA is not a prerequisite in this project workflow; code review, Windows automated builds/tests, signatures, payload integrity and Store-required metadata remain relevant.

Microsoft references: [Manual package validation](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/manual-package-validation), [MSI/EXE certification](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/app-certification-process), [IME compatibility](https://learn.microsoft.com/en-us/windows/apps/develop/input/input-method-editor-requirements).
